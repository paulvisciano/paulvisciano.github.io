## Marketing Strategy
1. **Product-led growth via templates**
   - Package the three existing repos as free, open-source starter kits.
   - Publish on design/template sites (e.g., sites that feature cool web apps and templates).
   - Include an agent prompt that guides cloning the repo and setting up a personal version.
   - Differentiator: custom UI + LightRAG integration (not just open-source pieces).
   - Apps are designed to run on localhost — users see the published demo but run their own private version.
2. **Field notes & build logs**
   - Short posts showing the actual stack (Llama CPP, LightRAG, local setup).
   - Attracts privacy/crypto/sovereignty crowd who already search for this.
3. **Google leverage**
   - Already dominating name search. Keep publishing to compound it.
4. **Social automation**
   - Daily generation of posts (already running). Future: second automation to publish to X/other platforms.
5. **Primary CTA on site**
   - Add clear call-to-action near top (Try the apps / Join waitlist / Book setup).
   - Make teaching offer feel like a product, not just a form.
